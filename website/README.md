# Zedd Weather — Project Website

A **static** frontend site that explains the Zedd Weather project: the
hardware, the three-node Raspberry Pi cluster, the sector intelligence
engines, the RMPE-2 blockchain protocol, the API, and deployment.

The content is vanilla HTML + CSS + JavaScript (no framework, no build
pipeline). To satisfy **GoDaddy Node.js Hosting** validation, the folder also
contains a tiny zero-dependency `server.js` that serves the static files on
`process.env.PORT`. This means the same folder deploys to:

- **GoDaddy Node.js Hosting** — zip upload (see below)
- **Any static host** — shared hosting `public_html`, S3, Netlify, etc.

## Quick preview

Serve locally from this folder:

```bash
cd website
node server.js          # then open http://localhost:3000
# or
python3 -m http.server 8080   # then open http://localhost:8080
```

## Deploying to GoDaddy Node.js Hosting (zip upload)

GoDaddy requires a `package.json` at the **root of the zip** (not nested in a
subfolder), plus `build` and `start` scripts, and it must NOT contain a
`node_modules` folder. This folder already meets every requirement:

- `package.json` — non-empty `name`, `version`, `main`
- `"build": "echo build"` — nothing needs compiling
- `"start": "node server.js"` — serves the site on `process.env.PORT`
- zero dependencies — nothing to install, no `node_modules`

### Steps

1. Zip the **contents** of this folder so `package.json` sits at the zip root.
   On Linux / macOS:

   ```bash
   cd website
   zip -r ../zedd-weather-site.zip . -x '*.DS_Store'
   ```

   The zip must look like this when opened:

   ```text
   package.json
   server.js
   index.html
   css/
   js/
   README.md
   ```

2. In GoDaddy Node.js Hosting, choose **Upload** → **Folder upload** and select
   that zip.

3. The platform runs `npm install` (nothing to do) and `npm run build`, then
   starts `npm start`. The site is served automatically on the port GoDaddy
   assigns via `PORT`.

> **Tip:** a ready-made zip (`../zedd-weather-site.zip`) is generated by the
> zip command above, or is available at the repo root.

## Alternative — static hosting (shared cPanel / public_html)

1. Upload the contents of this folder into `public_html` (cPanel File Manager
   or FTP). `index.html` is served automatically; `server.js`/`package.json`
   are simply ignored by the web server.
2. Enable the free SSL certificate from cPanel / GoDaddy hosting settings.

## Structure

```text
website/
├── index.html       # Full project documentation (single page)
├── css/styles.css   # Dark emerald theme, responsive, no framework
├── js/main.js       # Nav drawer, sector tabs, scroll reveal, progress bar
├── server.js        # Zero-dependency Node static server (GoDaddy Node.js hosting)
├── package.json     # name/version/main + build/start scripts
└── README.md        # This file
```

## Notes

- **Custom domain:** GoDaddy auto-serves `index.html` from the document root,
  so no rewrites are needed on shared hosting.
- **HTTPS:** enable the free SSL certificate from cPanel / GoDaddy Hosting
  settings so the site loads over `https://`.
- This site is documentation only. The full dashboard application lives in the
  repo root under `src/` (React) and `Zweather/` (FastAPI backend).
